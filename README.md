# Палитра морилок INK

Сайт для подбора оттенка морилки INK: 150 образцов на ясене, поиск по народным названиям, подбор ползунками и кнопки «вот такой, но…». Для каждого оттенка показан рецепт смешивания из базовых концентратов на нужный объём.

Сайт статический: `index.html` и картинки в `img/`. Сборка не нужна, GitHub Pages отдаёт файлы как есть.

## Как устроено

- `index.html` — готовая страница, данные всех 150 оттенков встроены в неё.
- `img/` — вырезанные образцы, 240×300, свет выровнен по бумаге.
- `data/shades.json` — коды, народные названия, тон, концентрация и состав на 1 л.
- `data/swatch-cuts.json` — где на исходных фото находится каждый образец.
- `tools/` — скрипты, которыми всё сделано:
  - `palette.py` — названия, составы вторичных цветов, расчёт рецептов;
  - `detect.py`, `grid.py`, `refine.py` — поиск и вырезание образцов на фото;
  - `qa.py` — проверка краёв вырезов и контрольные листы;
  - `wb.py` — выравнивание света по бумаге;
  - `build.py` — сборка `index.html` из `tools/index.src.html` и картинок.

## Как поменять названия

1. Отредактировать словарь `N` в `tools/palette.py`.
2. Проверить, что названия не повторяются: `python3 tools/palette.py data/shades.json`.
3. Пересобрать страницу: `python3 tools/build.py <папка с вырезами> tools/index.src.html .`

## Ограничения

- Цвета сняты с фотографий, поэтому зависят от съёмки и экрана. Перед работой сверяйтесь с живым образцом.
- Выкрасы на ясене: на другой породе тот же состав ляжет иначе.
- Проценты в рецептах считаются объёмными, «основа» — разбавитель производителя.
- Народные названия придуманы по виду образцов, это не названия производителя.
